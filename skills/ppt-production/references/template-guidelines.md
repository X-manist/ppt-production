# 参考模板使用规范

用户提供参考模板时必须执行本文件。未提供模板时，按需求确定统一视觉规范，不能假定存在某个特定文件。

- 以用户提供的参考模板为基准，选取与当前内容结构相符的代表页，提取可复用的标题、文本框、图框、表格、总结条和页脚样式。
- 配色、强调色、圆角、线宽及组件间距沿用参考模板。不预设特定品牌色，不混入其他稿件的视觉规范。
- 布局按内容结构选择，两栏、三栏和上下结构分别匹配相应版式，禁止所有页面套同一种布局。
- 从模板提取同级图片边界、同级文本起始边与基线、内边距和组内间隔，作为共用对齐线。主内容区左右留白必须关于页面中心对称，不能只对齐最外层卡片而忽略内部图片与文字。
- 页面长句改为关键词标签，详细解释写入备注。模板中的文本框必须按目标环境真实字体 TTF、字重与字号重新度量，不能沿用经验字宽或 LibreOffice 中恰好放得下的尺寸。LibreOffice 只用于检查布局对齐。
- 检查模板母版、版式与实际页面的 logo、页码及页脚位置，明确保留内容和可编辑范围，新增文字或结论条必须避让。
- 复杂或高密度页面给制作 agent 提供组件级蓝图，包含位置、尺寸、标签、连接关系与标注。密度要求由内容与用户要求决定，不用固定元素数量凑页面。
- 模板中的旧字号、旧文案、图片裁切和动画设置不自动成为当前任务的例外。仍须满足主文件的硬性要求，冲突时根据用户对当前任务的明确指示处理。
- 制作与合并后对照参考模板检查字体层级、配色、留白和组件样式。改动共享母版或版式前检查所有受影响页面，禁止误改用户未指定的内容。
